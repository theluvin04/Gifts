Gifts - FONT SYSTEM PATCH
=========================

Cach dung tren Windows:
1. Giai nen ZIP NAY truc tiep vao THU MUC GOC repo Gifts.
   Thu muc goc la noi co package.json, src/, public/.
2. Neu Windows hoi ghi de QuickFontPicker.tsx thi chon Replace.
3. Double click: APPLY_FONT_SYSTEM.bat
4. Chay: npm run build

Sau khi ap dung:
- File font de vao: public/fonts/custom/
- Khai bao font o: public/fonts/manifest.json
- Khong can sua picker moi lan them font.
- Text va Button trong editor deu co picker font.
- Preview/editor/trang khach dung cung font local.

Vi ZIP khong kem file font thuong mai/copyright, ban tu copy file .woff2/.woff/.ttf/.otf cua minh vao public/fonts/custom/.
Xem public/fonts/README.md va manifest.example.json de them font.
