V10 — Page delete + long page sizing

- Xóa trang luôn hoạt động. Nếu chỉ còn 1 trang, trang hiện tại được xóa và thay bằng 1 canvas trắng mới.
- Trang dài mặc định: 1366 × 3500 (logical desktop design).
- Mobile long page: 390 × ~2520 khi desktop H=3500.
- Public long page chạy full viewport width và cuộn dọc tự nhiên.
- Editor trang dài có vùng cuộn riêng nên canvas dài không bị cắt / mất phần dưới.
- Preset chiều cao: 2000 / 2600 / 3200 / 3500 / 4000.
